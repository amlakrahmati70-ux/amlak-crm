# تست رگرسیون دائمی — CRM املاک

این پوشه یه ابزار تست خودکاره که بعد از هر تغییری تو برنامه (چه خودتون بدید، چه هر Claude دیگه‌ای)، در چند ثانیه چک می‌کنه هیچی که قبلاً درست بود، خراب نشده باشه.

## نصب (فقط یک‌بار)

روی کامپیوتری که Node.js داره (نسخه ۱۸ به بالا):

```
cd test-suite
npm install playwright
npx playwright install chromium
```

## اجرا (هر بار بعد از یه تغییر)

```
node crm-regression-test.js /path/to/CRM_amlak_vNN.html
```

اگه مسیر فایل رو ندید، خودش دنبال جدیدترین فایل `CRM_amlak*.html` توی همین پوشه می‌گرده — پس ساده‌ترین کار اینه که همیشه آخرین نسخه‌ی فایل رو کنار همین اسکریپت کپی کنید و فقط بزنید:

```
node crm-regression-test.js
```

## خروجی چیه؟

یه لیست ✅ یا ❌ برای هر تست، و در پایان یه خلاصه. اگه حتی یه ❌ باشه، برنامه با کد خطا تموم می‌شه — یعنی «قبل از دادن این فایل به کاربر واقعی، این مورد رو بررسی کن».

## این اسکریپت چی رو چک می‌کنه؟

- سالم بودن سینتکس کد (خطای جاوااسکریپت نباشه)
- تابع یا آیدی تکراری نباشه
- همه‌ی ۱۴ تب اصلی و ۴ زیرنمای اطلس بدون خطا باز بشن
- چند تا باگ خاص که قبلاً پیدا و رفع شدن، دوباره برنگردن (فرمت تاریخ، جداکننده‌ی اعداد، هشدار قیمت کم، منبع فایل، فیلد بودجه‌ی لید، پیام به مالک، حذف برج/مجتمع، تشخیص خیابان)

## وقتی خودتون یا یه Claude جدید یه چیز جدید رو درست کردید

بهتره یه تست کوچیک برای همون باگ هم به همین فایل اضافه بشه (توی تابع `runBrowserChecks`، دنبال بخش «تست‌های اختصاصیِ باگ‌هایی که قبلاً پیدا و رفع شدن» بگردید و از همون الگو یکی جدید اضافه کنید) — این‌جوری این فایل هر ماه قوی‌تر می‌شه و هیچ باگ رفع‌شده‌ای دیگه برنمی‌گرده.
